## Limitations

- Synthetic world and cases; labels are derived from planted facts, which may favor the rule-based reference implementation that encodes the same rules.
- The `rules` framework is a deterministic upper reference, not an AI system.
- LLM frameworks share deterministic retrieval for research/policy/data; they differ in intake, planning and reporting.
- With few trials per case, confidence intervals are wide; differences inside overlapping CIs are not significant.
- Cost uses a static price table and is an estimate (0 for unpriced models).
