# POL-ONB-002: Compliance evidence before access

## Rules

- **POL-ONB-002.R1** A valid, unexpired SOC 2 Type II report is required before partner portal access is granted.
- **POL-ONB-002.R2** ISO 27001 certification alone is NOT sufficient for portal access.
- **POL-ONB-002.R3** If the SOC 2 report is missing or expired, the platform must request it from the requester and must not grant access.
