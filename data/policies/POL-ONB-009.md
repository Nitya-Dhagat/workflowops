# POL-ONB-009: Duplicate onboarding submissions

## Rules

- **POL-ONB-009.R1** If an onboarding ticket for the partner is already open, a new onboarding must not be started; the request is linked to the existing ticket.
- **POL-ONB-009.R2** No new onboarding task is created for duplicate submissions.
